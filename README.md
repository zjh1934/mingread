# 朗读女 Neo

**选中文字，按 F1 就朗读。** 一个面向低视力人群的 Windows 桌面朗读工具，本地语音优先，端到端约 **150ms** 出声。

> 本项目是与同名旧版商业软件**无关的独立重写**，不复用其任何代码与资源。详见文末「与旧版的关系」。

---

## 为什么做这个

屏幕阅读器（如 NVDA）解决的是「读整个界面」，但低视力用户在**阅读网页正文、文档段落**时更常见的需求是：**只想听我正在看的这一段**。

系统自带的「讲述人」需要先选中、再点菜单、再等语音；多数在线 TTS 工具要复制粘贴到网页里。这条路径的每一步都在消耗耐心。

朗读女 Neo 把这件事压成一个动作：**选中 → 按 F1 → 出声**，并且：

- **不等网络**：优先用本机离线语音，冷启动后稳态 **155ms**（P95 169ms）出声；
- **不动你的剪贴板**：读完后原样还原；
- **不出声失败**：任何失败都有语音说明原因，绝不静默。

## 功能

| 能力 | 说明 |
|---|---|
| **划词朗读** | 任意程序选中文字，按 `F1` 朗读；`Ctrl+Alt+R` 等可换绑 |
| **本地神经语音** | 微软晓晓 / 云希（经 NaturalVoiceSAPIAdapter 注册为系统语音），离线、无网可用 |
| **系统语音兜底** | 未安装神经语音时，自动使用系统内置中文语音（音质一般但极低延迟） |
| **在线兜底** | 本地全不可用时才走在线合成，UI 明确标注「在线」 |
| **屏幕放大** | 全局热键放大跟随鼠标，供低视力用户看细节 |
| **悬浮球** | 常驻小窗，单击朗读选中文字，右键菜单 |
| **长文听书** | 导入 txt / md，分句流式合成，支持倍速、跳句、导出 MP3 |
| **音色源扩展** | 可自行添加音色仓库（manifest），从源里发现并安装新发音人 |
| **无障碍** | 字号 1.0–2.0×（全界面跟随）、高对比度主题、44px 目标尺寸、键盘全可达、状态变化语音播报 |

## 环境要求

- Windows 10 / 11 x64（Windows 7 未测试）
- Node.js 18+（开发/打包）

## 快速开始

```bash
cd app
npm install

# 开发（Vite + Electron）
npm run dev

# 打包（产出 NSIS 安装包 + 免安装 zip 到 app/release/）
node node_modules/electron-builder/out/cli/cli.js --win nsis zip
```

> 仓库不含 `node_modules`、打包产物与离线语音包（约 142MB，运行时按需下载到本机）。

## 几个值得说的工程结论

这些都是踩过之后写进代码注释的，供后来者少走弯路：

**1. F1 可能根本抢不到。** `globalShortcut.register` 在热键被其他程序独占时永远返回 `false`。本项目用 koffi 安装低级键盘钩子，从系统输入链最前端旁路捕获按键（只监听、不拦截、不记录内容）。

**2. 在线语音有物理下限。** 每次合成都要重新 TLS 握手（实测 0.87s），加服务端首包，理论下限约 1.2s —— 预连接也救不回来。所以本地引擎是唯一出路。

**3. 系统自带语音被白名单挡住了。** 音色选择一度只认晓晓/云希，把系统自带的 Huihui 直接丢弃，导致本地引擎被判「不可用」而回退到 2 秒的在线链路。而它走常驻通道合成只要 **18–43ms**。

**4. 窗口一直等 `ready-to-show` 会白等 3.4 秒。** 实测 React 1.6s 就挂载完成，3.4s 是 `ready-to-show` 被资源拖住的假象。改为导航开始后 140ms 先显示骨架，窗口出现从 3390ms 降到 **1348ms**。

**5. 关窗 = 收进托盘，不能真销毁。** 托盘点击、悬浮球指令、热键结果全靠 `win.webContents.send`；窗口一销毁就是 `mainWindow=null`，三者同时静默失效。

## 第三方组件与资源

| 组件 | 用途 | 许可 |
|---|---|---|
| [NaturalVoiceSAPIAdapter](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter) | 把微软自然语音注册为 SAPI 语音 | 见其仓库 |
| koffi | N-API FFI（键盘钩子、系统放大接口） | MIT |
| Electron / React / MUI | 应用框架 | MIT |

**不随仓库分发**：微软语音资源（MSIX）、`Magnification.dll` 等系统组件均于运行时从官方渠道获取或使用系统自带副本。
