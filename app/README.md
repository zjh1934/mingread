# 朗读女 Neo

> 面向**低视力人群**的 Windows 无障碍辅助工具：**把屏幕放大到看得清，把看不清的字读出来。**
> 对标的是 Windows 放大镜 / ZoomText 这类**放大 + 朗读辅助工具**，不是喜马拉雅那类**听书 App**。
> 定位与验收口径见《无障碍定位说明.md》《朗读女Neo-无障碍设计基线-低视力版.md》。

---

## 先正名：这是什么，做给谁的

**首要用户群是低视力人群**——他们**还在看屏幕**，但看不清、看不久、看不全。

所以本项目的第一优先级不是朗读，而是**视觉增强**：能放大就别让他眯着眼睛看，能提对比度就别让他凑到屏幕前，实在看不动了再由朗读接手。
朗读的作用是**「替他看得省力」，不是「替他看」**。

| 判断项 | 听书 App（喜马拉雅等） | 朗读女 Neo |
|---|---|---|
| 用户当时在干什么 | 闭着眼 / 离开屏幕听 | **盯着屏幕看，只是看不清** |
| 内容从哪来 | 平台曲库里的书 | **屏幕上任意程序里的任意文字**（浏览器 / Word / PDF / 微信……） |
| 交互起点 | 打开 App → 找书 → 播放 | **选中文字 → 按热键 → 出声** |
| 核心指标 | 内容够不够多、推荐准不准 | **放大倍数、对比度、出声延迟** |
| 控件尺寸取向 | 越小越精致 | 越大越好，主操作 ≥ 44×44 |
| 断网时 | 内容还在，照听 | 视觉增强必须照常可用 |

三条定位事实（写给后来改代码的人，别再改回听书软件）：

1. **不是盲人专用**：用户是低视力，还看得见。不追求 NVDA / JAWS 级别的屏幕阅读器兼容，不做盲文，键盘全可达降为保底项而不是阻断项。
2. **屏幕缩放是核心功能，不是附属功能**：放大与朗读是低视力用户的两条腿，缺一条就站不稳。
3. **绝不静默失败**：抓不到选区就明确说「未获取到选区」，不拿旧剪贴板冒充。

## 核心能力（四件套）

| 能力 | 解决什么 | 当前状态 |
|---|---|---|
| **放大** | 全局屏幕缩放（LensZoom）：任意位置 `Ctrl+Alt+=` 放大一档 / `Ctrl+Alt+-` 缩小 / `Ctrl+Alt+0` 退出，画面跟随指针，倍率上限最高 32x，缩回 1x 自动退出 | ✅ v2.3 已可用 |
| **对比度** | 高对比配色、字号可缩放、大点击目标，压低「看久了眼疲劳」 | ✅ 已就位：WCAG AAA（≥7:1）高对比主题、字号 1.0–2.0x 四档可缩放、主操作 ≥ 44×44 |
| **朗读** | 选中 → 热键 → 出声，逐句流式，长文边合成边播 | ✅ 已可用（本地 NVSA 离线优先 + 微软 Edge 在线兜底，晓晓 / 云希） |
| **低延迟** | 热键 → 反馈音 ≤ 200ms、→ 人声 ≤ 1000ms | 本地 NVSA 引擎（离线）目标 ≤ 300ms，是根治路径；在线链路兜底 |

> 延迟是可用性红线，不是性能锦上添花。低视力用户按下热键后是在**等声音**，等三秒就等于没做。

## 语音链路：本地 NVSA 优先 + Edge 在线兜底

早年塞了三套语音：内置模型（Kokoro）、微软语音包（NVSA + 晓晓/云希）、系统语音库，代价是安装包 700MB+ 还要管理员授权，全部砍掉。v2.3.1 起重开**本地 NVSA 引擎**（微软神经语音本地运行，离线、百毫秒级），形成两级链路：

**本地 NVSA（晓晓 / 云希，离线优先）→ 微软 Edge 在线语音（晓晓 / 云希，兜底）**

- 本地与在线是**同一套微软神经语音**，音质一致；哪个引擎出声对用户无感，降级时会明确播报原因；
- NVSA 语音包**不随安装包分发**：首次运行自动下载装配（约 140MB，一次 UAC 授权，之后离线可用），装完即用；
- Edge 兜底的前提是**联网**（断网时会明确提示，不会静默失败）；
- 安装包约 90MB，不含任何语音模型。

> ⚠️ **澄清一处历史误记**：早年「音质还不理想」被写在三套方案并列的一句话里，容易被读成是 NVSA 的问题。
> 事实是：那个评价**属于内置的 Kokoro 模型**。NVSA 跑的是**与在线 Edge 完全相同的微软神经语音**（晓晓 / 云希），本地与在线音质一致，不存在音质退化。

## 功能

- **屏幕缩放**（v2.3，复刻 macOS 缩放）：任意位置按 `Ctrl+Alt+=` 放大一档 / `Ctrl+Alt+-` 缩小一档 / `Ctrl+Alt+0` 退出；画面跟随指针（指针为不动点 / 指针居中 / 边缘推动三种策略），整数倍步进像素锐利，放大时鼠标穿透不影响操作下层界面；倍率缩回 1x 自动退出。托盘菜单、悬浮球右键、设置界面均可控制
- **划词朗读**：在浏览器 / Word / PDF / 微信里选中文字，按 `Ctrl+Alt+R` 直接读（默认热键；`F1` 保留为可选预设。自动抓取选中内容，读完还原你的剪贴板）
- **桌面悬浮球**（v2.2）：桌面右上角常驻小圆球，**单击朗读当前选中文字**，可拖动、位置自动记忆，设置里可关；球变红表示热键被占用；右键菜单可控制播放与缩放
- 文本朗读：粘贴 / 输入 / 导入 `.txt` `.md` `.epub`（epub 自动拆章节）
- 逐句流式播放：第一句合成完就出声，后面边播边合成，长文不用等
- 播放控制：播放 / 暂停 / 停止 / 进度拖动 / 上一句·下一句 / 当前句高亮
- 语速、音调、音量；定时关闭（睡前听）
- 导出 MP3（长文自动分段合成后拼接）
- **复制即读**：在任意程序复制文字自动朗读——低视力下「复制」本身就是「我正盯着这段看」的信号，属于刚需。**默认开启**（1500ms 节流 + 2 万字长度上限，超长跳过并语音播报原因），设置里可关
- 系统托盘、深浅色主题、窄窗口自适应

## 安装 / 使用

1. 运行 `朗读女Neo-2.3.0-安装包.exe`（或解压 `朗读女 Neo-2.3.0-win.zip` 直接运行）。
2. 粘贴文字 → 点「开始朗读」；或在任意程序选中文字 → 按 `Ctrl+Alt+R`（或单击桌面悬浮球）。
3. 屏幕缩放：任意位置按 `Ctrl+Alt+=` / `Ctrl+Alt+-` / `Ctrl+Alt+0`。
4. 音色只有两个：**晓晓**（女声）/ **云希**（男声）。

### 关于热键占用

`Ctrl+Alt+R` 是默认全局热键。旧版「朗读女」常驻占的是 `F1`——换用 `Ctrl+Alt+R` 正好绕开；若你在设置里主动选回 `F1` 等预设，而此刻**旧版「朗读女」或其他软件正开着**，可能注册失败。新版会明确告诉你：

- 托盘弹出气泡「热键被占用」；
- 设置 → 全局热键 显示「⚠️ 注册失败（被占用）」；
- 桌面悬浮球变红并带感叹号。

**解决办法**：退出占用该热键的程序（尤其是旧版朗读女），或在设置里把热键换成其他预设（`F1` / `Ctrl+Alt+F1` / `Shift+F1`）或自定义组合，保存后立即生效。

## 从源码构建

```bash
npm install
python scripts/make-icon.py     # 生成图标（仅首次）
npm run build:renderer
npm run dist                    # 出安装包 + 免安装 zip
```

自检：

```bash
npm run check                          # 主进程语法
node scripts/probe-tts.js list         # 音色（应为 2 个）
node scripts/probe-tts.js synth        # 试合成一段
node scripts/smoke.js                  # 端到端冒烟
python scripts/selfcheck_all.py        # 汇总（需联网）
```

## 目录结构

```
app/
├─ src/main/
│  ├─ index.js             # 入口（userData 固定 ASCII 路径）
│  ├─ ttsBridge.js         # 唯一引擎：Edge
│  ├─ backends/edgeTtsBackend.js
│  ├─ selectionReader.js   # Ctrl+Alt+R/悬浮球划词：Ctrl+C 抓取 + 还原剪贴板
│  ├─ hotkeyTray.js        # 全局热键（默认 Ctrl+Alt+R，F1 为可选预设，占用可检测）+ 托盘
│  ├─ floatBall.js         # v2.2 桌面悬浮球（置顶小窗 / 拖动 / 右键菜单 / 状态广播）
│  ├─ zoomController.js    # v2.3 屏幕缩放控制器（热键/滚轮触发、几何变换、覆盖层编排）
│  ├─ zoomPreload.js       # v2.3 缩放覆盖层预加载（getUserMedia 屏幕流）
│  ├─ zoom-overlay.html    # v2.3 缩放覆盖层页面（video + CSS transform）
│  ├─ clipboardMonitor.js  # 复制即读（默认开：节流 + 长度上限，可关）
│  ├─ voiceSetup.js        # 状态（在线可用 / 上次错误）
│  ├─ exporter.js          # 分段合成 → MP3 拼接 / 字幕
│  ├─ epubReader.js        # 零依赖 epub 解析
│  └─ ipc.js               # 通道定义
├─ src/renderer/           # React + MUI + Zustand
├─ public/floatball.html   # v2.2 悬浮球页面（静态，零依赖）
└─ resources/icon.*        # 图标
```
