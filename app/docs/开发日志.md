### 一、环境实况（修正交接文档的关键假设）

- **运行环境 = 用户 Win10 本机（管理员会话，Git Bash + PowerShell 工具）**，不是交接文档假设的 Linux 沙箱。第二章环境差异表大部分失效。
- 本机为**精简网吧电脑**：装有 QQ网吧客户端、Pubwin OL、迅雷；WorkBuddy（pid 4928）为会话宿主。
- **F1 当前被本会话外程序稳定占用**（holder 探针抢注失败；旧版朗读女/网吧客户端/WorkBuddy 之一）——应用的冲突引导 + 自动重试正是为此刻设计；待用户退出占用方后复测端到端。
- 沙箱约束（agent 会话层，不影响用户正常运行）：① `reg.exe` 在程序黑名单；② Bash 内禁 spawn powershell（须走 PowerShell 工具）；③ PowerShell 工具运行空间解析不到 GAC 程序集（System.Speech 探测曾误报"缺失"，实际系统可用）；④ `Start-Process` 因会话注入的 http_proxy/HTTP_PROXY 大小写重复键而抛异常；⑤ 代理变量是 WorkBuddy 本地代理（127.0.0.1:63638），**直连外网实际通畅**。
