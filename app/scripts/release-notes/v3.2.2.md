选中任意程序里的文字，按 `F1` 就开始朗读。读完自动还原你的剪贴板。

也可以切到**鼠标停住就读**：指针在文字上停 0.6 秒，自动读那一段，读到的位置会在屏幕上框出来。

默认使用**本机离线语音**（微软晓晓 / 云希），从选中到出声约 **0.15 秒**，不联网也能用。

## 下载哪个

| 文件 | 适合谁 |
|---|---|
| `MingRead-3.2.2-setup.exe` | 一般使用。装完有开始菜单和桌面图标，可正常卸载 |
| `MingRead-3.2.2-win-x64.zip` | 不想安装。解压后双击 `明读.exe` 直接用 |

## 这个版本相比 v2.4.0 改了什么

**屏幕放大换成了系统接口**（`Alt` + 滚轮）

旧版是「截屏 + CSS 缩放」，会出现鼠标周围一圈圈方形线条、进入时先闪一下加载页。现在改用 Windows 自带的放大接口（Magnification API），系统直接把屏幕内容画进原生窗口，中间没有任何自绘——**那些伪影从结构上消失了**。滚轮连续推进，手感对齐 macOS。

**新增「鼠标悬停朗读」**

不用选中、不碰剪贴板：指针停在文字上约 0.6 秒就自动读。三档详细度（一句 / 一段 / 本段+下文），读到的位置会用紫框标出来。和热键朗读**二选一**，首页可以切换。

它靠系统 OCR 取词，所以浏览器、PDF、图片里的字都能读；代价是不懂语义，停在图标上可能读到旁边的零碎字。

**其他**

- 关窗不退出（驻留托盘，`F1` 随时可用）；右键托盘图标可退出
- 找不到鼠标指针？主页有「打开指针大小设置」，一键跳到系统那页
- 首屏有微信二维码（反馈问题）和打赏码
- 启动从 3.4 秒压到 1.3 秒

## 这一版修的问题

- **热键提示音是假开关**：界面说已开启，实际不响，重启还自己关回去
- **大字号下文字叠到别的卡片上**：1.5x/2.0x 时，限高滚动的区域变成了溢出
- **暂停听书时鼠标停一下，整本书进度会被清空**：现在会跳过并提示
- **音色只能看到前两个**：从音色源里装的发音人根本选不到
- **一个迟早会炸的循环依赖**：设置模块为了一个常量反向加载了 1100 行的缩放控制器

## 已知限制

- 仅 Windows x64；Windows 7 未测试
- 悬停朗读取词走 OCR：小字（10px 以下）、深色背景、代码会认错
- 管理员权限的窗口读不到（系统权限限制，不是 bug）
- 安装包未做代码签名，首次运行可能被 SmartScreen 或杀软拦一下，选择「仍要运行」即可
