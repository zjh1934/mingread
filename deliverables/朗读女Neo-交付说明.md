> 现行状态以 `新对话接手说明.md` 为准。

## 二、核心：四层语音引擎

| 引擎 | 名称 | 是否需要网络 | 是否需要授权 | 说明 |
|---|---|---|---|---|
| `builtin` | 内置引擎 | 否 | 否 | 随包内置 Kokoro 神经语音模型，8 个中文音色（4 女 4 男），装完就能读 |
| `ms` | 微软原生发音人 | 否 | 一次 | 晓晓 / 云希，组件随包内置，点一次「启用」后永久离线可用 |
| `sapi` | 系统语音库 | 否 | 否 | 系统已装语音 + 可导入第三方 SAPI 语音包（扩展入口） |
| `edge` | 在线（Edge） | 是 | 否 | 兜底方案，音质接近微软在线神经语音 |

失败会自动按 内置 → 微软 → 系统 → 在线 的顺序降级，不会「点了没反应」。

## 三、第一次怎么用

1. 双击安装包安装（或解压 zip 后运行 `朗读女 Neo.exe`）。
2. 首次打开会弹出「语音引擎」面板：
   - 内置引擎已经是就绪状态，直接就能读；
   - 想要音质最好的晓晓/云希 → 点「启用微软原生发音人」，会弹一次管理员授权（UAC），同意即可，之后永久离线可用。
3. 把文字粘进左侧编辑区（或导入 txt / md / epub），点「开始朗读」。
4. 长文会自动**逐句边合成边播放**——第一句合成完就出声，后面在后台排队，不用等整篇。

## 四、源码怎么跑起来

源码包不含语音资产（体积太大）。补齐方式：

1. **内置模型**：下载 `kokoro-int8-multi-lang-v1_1.tar.bz2`
   （https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models ，
   国内可用 `https://gh-proxy.com/` 前缀），解压后放到 `app/resources/tts/kokoro/`，
   并把压缩包自带的 `voices.json` 换成源码包里的那份（里面是精选 8 音色的 sid 映射）。
2. **微软语音组件**：下载 NaturalVoiceSAPIAdapter v0.2.10 与晓晓/云希两个 MSIX
   （地址见 `THIRD-PARTY-NOTICES.md`），按 `resources/voices/ms/manifest.json` 的结构放置。
3. 然后：

```bash
cd app
npm install
python scripts/make-icon.py     # 生成图标
npm run build:renderer
npm run dev                     # 开发调试
npm run dist                    # 打包安装包 + 免安装 zip
python scripts/selfcheck_all.py # 自检
```

## 六、已知限制（如实说明）

1. **内置引擎速度受 CPU 影响**：本机（虚拟机）实测约 1 倍速（合成 1 分钟音频约需 1 分钟），
   普通台式机通常会快 2-3 倍。已做逐句流式播放 + 预取缓冲，弱机上连续播极短句时可能出现短暂缓冲。
   追求速度可切微软原生发音人（实测约 0.5 倍速）。
2. **音高调节**：内置引擎与微软原生走 SAPI 通道时，音高为轻微调整；在线 Edge 引擎支持完整音高。
3. **第三方语音包**：`导入第三方语音包` 会调用其官方安装程序，装完点「重新扫描」即可出现在音色列表。
4. **微软语音包的许可**：MSIX 为微软商店原始包，微软未明确授权第三方再分发，本项目定位个人自用；
   对外发布前请评估，或删掉 `resources/voices/ms` 只保留内置引擎 + 在线兜底（见 THIRD-PARTY-NOTICES.md）。
5. **尚未做**：字幕（SRT/LRC）导出入口的界面按钮、批量导出界面入口（能力已在主进程实现）。
