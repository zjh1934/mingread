# 朗读女 Neo v2.1.0 · 交付说明

> ⚠️ 本文是 v2.1.0 当时的历史记录（彼时默认热键为 F1、复制即读默认关）。**v2.3.1 起默认热键已改为 `Ctrl+Alt+R`（F1 仅为可选预设）、复制即读默认开、语音链路为本地 NVSA 优先 + Edge 在线兜底**——现行状态以 `新对话接手说明.md` 为准。

## 这一版做了什么（按你的三条要求）

| 你的要求 | 这版的处理 |
|---|---|
| 不保留内嵌发音人，只用 Edge 那一种 | 内置 Kokoro 模型、微软语音包（NVSA + 晓晓/云希）、系统语音库 **全部删除**；只剩一条链路：文本 → Edge 在线语音 → mp3 |
| 只留晓晓 / 云希两个音色 | 音色列表就两行：晓晓（女）、云希（男），其余全部清掉 |
| 试听/播放区出现乱码 | 已修：① 文本读取改为 UTF-8/GBK 自动识别（中文 txt 常见 GBK，之前会整篇乱码）；② 删掉 SAPI 那条会把中文以 GBK 送进 PowerShell 的老链路；③ 渲染层清除了所有非必要的编码转换，句级字幕只显示原文 |
| 缺少「任意处选中文字按 F1 朗读」 | 已实现：全局热键 **F1** → 自动复制当前选中内容（读完还原你原来的剪贴板）→ 直接朗读，不改动编辑器内容 |
| 软件太臃肿 | 安装包 **336MB → 77MB**，免安装版 393MB → 105MB；asar 内只剩 1.3MB；不再需要管理员授权、不写注册表 |

## 使用

1. 装好打开 → 粘贴文字 → 「开始朗读」。
2. 或者在**任何程序**里选中文字 → 按 `F1` → 立刻朗读（再按 `F1` 读新选中的内容）。
3. 音色在右侧切换：晓晓 / 云希。右上角绿点表示在线可用；变红点说明网络断了，点一下可重试。
4. 导出只有 MP3（长文会自动分段合成再拼接）。

## 需要你知道的

1. **必须联网**。这版没有任何离线语音，断网会明确提示「在线合成失败，请检查网络」，不会假装在播。
2. **F1 的抓取原理是"发一次 Ctrl+C"**：如果某个程序屏蔽了复制（少数 PDF 阅读器、部分游戏），抓不到内容时会退化为朗读剪贴板里已有的内容，并给出提示。
3. **升级请先退出旧版**：v2.0 和新版共用单实例标识，旧进程在跑会导致新版本启动后直接退出。安装新版前先在托盘退出 v2.0。
4. v2.0 的两个大文件（335MB 安装包 / 393MB 免安装包）如果确认不用了，说一声我从项目资产里删掉。
5. 之前实测时在你的系统里注册过 NVSA（所以系统语音多了晓晓/云希）。这版不再使用它；要清掉的话，v2.0 界面里点过「停用」，或者我给你一条命令注销。
